新闻博客主页 · 4 套模板参考

每套都是独立可打开的 HTML 文件（占位图为 CSS 渐变，无任何外部依赖）。点击卡片下方按钮可全屏预览。
模板 A

杂志风（参考 Amazing Architecture）

大图封面 + 侧边小卡、网格卡片流、横向专题滚动条、分类大图入口。图片优先，适合建筑/设计/摄影类媒体。

核心模块：Hero 主图+副卡 / 最新发布 4 列网格 / 专题横滑 / 分类入口 / 订阅条

模板 B

新闻门户（参考 Big News Network）

顶部快讯滚动条 + 大头条+右侧快讯列表、三栏头条、按频道分区（左图头条+文字列表）、热搜榜侧栏。信息密度高，适合综合资讯类。

核心模块：快讯 ticker / 头条区 / 三栏头条 / 科技·财经·体育分区 / 热搜榜+标签云+广告位
打开预览 ↗
模板 C

博客流（参考 Vegas Newser）

标签 pill 导航、推荐横幅、单列图文列表（缩略图+标题+作者+时间+标签）、粘性侧栏（关于/热门/标签云/订阅）、分页。适合地方新闻/个人博客。

核心模块：标签导航 / 主编推荐横幅 / 文章流+标签 / 分页 / 关于+订阅侧栏

模板 D

现代混合版（自动轮播 + 大小卡混排）

自动播放 Hero 轮播、大小卡片混排网格、图文列表 + 趋势榜/编辑推荐侧栏、粘性头部。现代杂志感，最接近产品级成品效果。

核心模块：自动轮播 / 混合网格 / 最新文章列表 / 本周趋势+编辑推荐 / 深色页脚
